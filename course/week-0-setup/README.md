# Week 0 — Set up

Before Session 1 · about 90 minutes

Get from an empty laptop to a working cloud account and a passing `make cloud-check`. Pick
**one** provider and stay on it all term — the grader never cares which.

## Read

- [Cloud portability reference](../reference/cloud-portability-reference.md) — why the code is
  split into three layers, and the contract every lab relies on

## Prepare

- Python 3.11 or newer, Docker (running), and Git on your laptop
- On Windows, WSL2 — the Makefile assumes bash

## Do

Follow **one** guide from start to the end of its Week 0 part:

| Guide | Choose it if |
|---|---|
| [Google Cloud](getting-started-gcp.md) | You can use a credit card for the free trial |
| [Azure](getting-started-azure.md) | You want no card: Azure for Students, from your university email |

## Due

| What | When |
|---|---|
| Your `make cloud-check` output posted in the course channel — **even if some lines say FAIL** | Before Session 1 |

A FAIL posted on the weekend is a five-minute fix. The same FAIL found in the room costs you the
session.
